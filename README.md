# 人狼DX オンライン / Jinro DX Online

「会話型心理ゲーム 人狼DX 新装版」(13役職)をオンラインで進行するためのWebアプリです。
各自のスマホで同じ部屋(合言葉コード)に入り、役職確認・夜の能力行動・投票をアプリ上で行います。
実際に集まって会話しながら遊ぶことを前提としているため、チャット機能はありません。

日本語・英語のどちらでも遊べます(右上の JA / EN で切り替え)。

## 収録している役職(13種)

市民 / 予言者 / ボディーガード / 霊媒師 / ハンター / 共有者 / 独裁者 /
人狼 / 裏切り者 / 内通者 / 妖狐 / 神様 / 恋人

役職の人数構成はホストが人数に応じて自由に編集できます(おすすめ配役の自動提案あり)。
人数が増えるごとに使える役職の幅が広がるようになっています(例: 予言者は5人〜、共有者は10人〜、恋人は13人〜など)。

## 司会(進行)は自動です

各フェーズは「制限時間が来る」または「全員の行動/投票が揃う」のどちらかで自動的に次へ進みます。
人間の司会役は不要です。ホスト(部屋を作った人)には「今すぐ進める」ショートカットボタンが表示されますが、
押さなくてもタイマー通りに自動で進行します。

## 動かし方(自分のPCで試す場合)

### 1. 必要なもの

- Node.js 20以上
- このプロジェクト一式

### 2. セットアップ

```bash
npm install
npm run dev
```

起動すると以下のように表示されます。

```
> 人狼DX オンライン版が起動しました: http://localhost:3000
> 同じWi-Fi内のスマホからは http://<このPCのIPアドレス>:3000 でアクセスできます
```

### 3. スマホからアクセスする(同じWi-Fiの場合)

サーバーを起動したパソコンのIPアドレスを確認します。

- Mac: 「システム設定」→「Wi-Fi」→ 詳細でIPアドレスを確認 (または `ipconfig getifaddr en0`)
- Windows: コマンドプロンプトで `ipconfig` を実行し、IPv4アドレスを確認

同じWi-Fiに繋がっているスマホのブラウザで `http://<IPアドレス>:3000` を開けば、全員が同じ部屋に参加できます。
ホストが「部屋を作成」→ 表示された5桁の合言葉コードをみんなに伝える(または「招待リンクをコピー」で共有)→ 各自「部屋に入る」からコードを入力、という流れです。

### 4. 本番用に起動する場合

```bash
npm run build
npm start
```

## Wi-Fiが違う人がいても遊べるようにする(本番デプロイ)

同じWi-Fiにいなくても合言葉コードだけで全員が繋がれるようにするには、このアプリをインターネット上のサーバーに
常時ホストする必要があります(自分のMac/PCを起動しっぱなしにする必要はなくなります)。

このアプリはWebSocket(リアルタイム通信)を使う常駐サーバー構成のため、Vercelのような静的/サーバーレスホスティングではなく、
Node.jsサーバーを常時起動できるホスティングが必要です。例:

- [Render](https://render.com) — このリポジトリには `render.yaml` を同梱済みなので、Renderで「New +」→「Blueprint」からこのリポジトリを選ぶだけで設定が読み込まれます。無料プランあり。
- [Railway](https://railway.app) — リポジトリを接続するだけで `Dockerfile` を自動検出してビルドします。
- [Fly.io](https://fly.io) — `fly launch` で同梱の `Dockerfile` を使ってデプロイできます。

同梱している `Dockerfile` はどのDocker対応ホストでもそのまま使えます(`docker build . && docker run -p 3000:3000 <image>`)。

デプロイ後は、そのサービスが発行するURL(例: `https://jinro-dx.onrender.com`)にスマホからアクセスすれば、
Wi-Fiが違っても・外出先でも、合言葉コードだけで同じ部屋に入れます。

アカウント作成やホスティングサービスへの登録はご自身で行っていただく必要があります(セキュリティ上の理由により、こちらでは代行できません)。登録後、リポジトリを接続していただければ、以降のデプロイ設定の調整はお手伝いできます。

## 技術構成

- Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- Socket.io によるリアルタイム同期(カスタムNode.jsサーバー: `server.ts`)
- ゲームロジックは `src/lib/game/` 以下にサーバー・クライアント共通で実装
- 表示文言は `src/lib/i18n/strings.ts` に日英まとめて集約(新しい言語を増やす場合もここを拡張)
